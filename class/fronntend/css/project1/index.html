FLEX

This is shorthand for flex-grow, flex-shrink, flex-basis combined. The second and third parameters (flex-shrink, flex-basis) are optional.

FLEX GROW

The defines the ability for a flex item to grow if necessary. It accepts a unitless value that serves as a proportion.
